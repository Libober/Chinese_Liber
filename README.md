# Attack on Hànzì

Сайт открывается через корневой `index.html`. GitHub Pages публикует сайт из корня репозитория.

| Папка | Содержание |
| --- | --- |
| `site/js/` | Логика сайта, тренировок и импорта |
| `site/styles/` | Оформление сайта |
| `site/data/` | Встроенные слова и предложения |
| `site/vendor/` | Сторонние библиотеки и лицензии |
| `assets/character/` | Изображения и варианты логотипа персонажа |
| `assets/illustrations/` | Дополнительные иллюстрации в локальной копии |
| `materials/reference/` | Справочный словарь HSK и локальные материалы для сверки |
| `tools/hanzi-materials/` | Скилл и скрипт сборки файлов для импорта |

Чтобы собрать новый набор, подготовь исходник по [инструкции скилла](tools/hanzi-materials/SKILL.md) и запусти команду из корня проекта. Для неё нужен Node.js 18 или новее.

```sh
node tools/hanzi-materials/scripts/build-materials.cjs источник.json materials/готовый-набор.json
```

Для загрузки открой **Настройки → Загрузить DOCX или JSON** на сайте и выбери готовый файл.
