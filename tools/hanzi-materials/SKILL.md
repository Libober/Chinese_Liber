# Подготовка материалов для Attack on Hànzì

1. Возьми слова из материалов пользователя. Сохрани ханзи, пиньинь с тонами и русский перевод. Выбирай тему по смыслу. Идентификаторы тем указаны в `site/js/study.js`.
2. Для каждого примера напиши естественное короткое предложение с однозначным русским переводом. Замени целевое слово одним `__`. Проверь, что предложение звучит естественно после подстановки. Запиши пиньинь всего предложения с подставленным словом, разделяя слоги пробелами. Проверь чтение многозначных знаков и нейтральные тоны по контексту.
3. Вокруг пропуска используй знакомые слова из словаря и лексику HSK 1–2. Если нужен другой термин, добавь к конкретному примеру `notes` с ханзи, пиньинем и коротким переводом. Скрипт проверяет словарь после автоматического деления на слова. Окончательно оценивай уровень и смысл вручную.
4. Сохрани исходный JSON вне папки готовых файлов. Из корня проекта выполни `node tools/hanzi-materials/scripts/build-materials.cjs источник.json materials/готовый-набор.json`. Исправь сообщения скрипта и повтори сборку. Команда создаёт новый файл по указанному пути.
5. Отдай готовый JSON для **Настройки → Загрузить DOCX или JSON**. Для проверки импорта используй отдельный профиль браузера, если основные данные пользователя должны остаться нетронутыми.

```json
{
  "format": "hanzi-materials-1",
  "words": [
    {
      "hanzi": "游泳池",
      "pinyin": "yóuyǒngchí",
      "meaning": "бассейн",
      "group": "fun",
      "examples": [
        {
          "prompt": "我去__。",
          "pinyin": "wǒ qù yóu yǒng chí.",
          "translation": "Я иду в бассейн.",
          "notes": []
        }
      ]
    }
  ]
}
```

Для файла со словами достаточно `hanzi`, `pinyin`, `meaning` и `group`. Чтобы добавить только предложения к встроенному слову, укажи его точные `hanzi` и `pinyin`, затем `examples`. Для переносимого набора с новыми словами указывай перевод и тему вместе с примерами. Каждая сноска содержит поля `hanzi`, `pinyin` и `meaning`.
